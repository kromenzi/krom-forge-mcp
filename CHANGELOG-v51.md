# KROM Forge v51 Changelog

## Added

- 72 MCP tools across 12 Frontier Operations systems.
- Mission runtime, checkpoint selection, deadlock detection and recovery routing.
- Causal decision graphs, counterfactual simulation and risk-capital allocation.
- Capability-market matching with evidence-backed delegation contracts.
- Knowledge consolidation, safety cases and release digital twins.
- Tool-composition planning, drift forecasting, human oversight and outcome learning.
- 28 behavioral tests for v51, raising the complete suite to 60 tests.
- Required v51 module and representative-tool checks in static verification.

## Changed

- Package version advanced to `51.0.0`.
- GitHub CI targets the isolated `v51` branch and emits `krom-v51-verification` artifacts.
- MCP capabilities boundary documents the Frontier Operations evidence model.

## Boundaries

- No merge to `main`.
- No manual Production promotion.
- Automatic provider previews are reported only after observed evidence.
- No external execution, approval, outcome, recovery or deployment success is inferred from a plan.
